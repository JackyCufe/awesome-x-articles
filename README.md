## 为什么有这个仓库

信息流里的好内容死了太快——一条精心写的长推，三天就被算法埋掉。
这里是我在 X 上逐条收藏、逐条读完、认为值得长期留存的长文集合。

每条都带一句话点评：它解决了什么问题、为什么值得你的 10 分钟。

## 收录标准

1. 长文或长推文串（不是碎片观点、不是新闻转述）
2. 有可复用的方法论、数据或一手经验（不是「我觉的」）
3. 读完能带走点什么——一个决策框架、一个踩坑记录、一个反直觉结论
