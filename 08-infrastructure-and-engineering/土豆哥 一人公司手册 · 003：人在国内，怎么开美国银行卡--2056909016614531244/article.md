### 你需要的四件套

开美国卡不需要绿卡，不需要 SSN（美国社会安全号码，只有公民和合法居民才有），但需要这四样东西：

### 第一步：申请 ITIN（最关键，也最耗时）

ITIN（Individual Taxpayer Identification Number）是美国国税局给非居民发的税务号，格式和 SSN 一样是 9 位数字，以 9 开头。大多数银行和银行卡公司接受 ITIN 替代 SSN。

**申请路线：找 CAA（Certifying Acceptance Agent）**

CAA 是 IRS 认证的中介，可以远程视频核验护照，不需要邮寄护照原件。这是在国内申请 ITIN 最安全的方式。

申请流程：

- 在网上找 CAA（国内代理淘宝搜"ITIN申请"，价格 1200-1800 元；英文 Fiverr 搜"ITIN"，$150-250）
- 提供护照扫描件 + 视频核验（5 分钟）
- 代理帮你填 W-7 表格 + 准备报税理由
- 提交给 IRS，等待 8-12 周
- 收到 IRS 寄来的 ITIN 确认信

**重要提示：**

- ITIN 下来后等 **1 个月再申请银行卡**，让银行系统把你的号入库
- 每隔 3 年需要用 ITIN 报一次税，否则号码会过期
- 申请 ITIN 不代表你成为美国税务居民，国内收入不会被美国征税

### 第二步：准备美国地址

银行会把银行卡实体卡寄到你的美国地址，也会用地址验证你的身份。**必须是私人住宅地址**，不能用转运仓库或明显的商业地址。

> 有朋友/亲戚在美国的地址当然最好，最稳定。没有的话，用下面的方法。

**推荐：Anytime Mailbox（ATMB）**

提供真实的美国私人地址，支持扫描信件和转寄回国，全程在线操作。

**第 1 步 — 注册并选州**

打开 [anytimemailbox.com](https://www.anytimemailbox.com/)，点击右上角 Sign Up。注册后可以看到全美 50 个州的可用地址，加州数量最多。

![图片 2](assets/003.jpg)

选择你想要的州，进入该州的地址列表。

![图片 3](assets/004.jpg)

**第 2 步 — 验证地址是私人地址**

列表里混有商业地址，必须先核验。用以下任意一个工具验证：

- USPS 官方查询：[tools.usps.com/zip-code-lookup.htm](https://tools.usps.com/zip-code-lookup.htm?byaddress)
- Smarty：[smarty.com/products/single-address](https://www.smarty.com/products/single-address)

看 **CMRA** 一项是否为 \`N\`——\`N\` 表示私人地址，\`Y\` 表示商业地址，必须选 \`N\` 的。

![图片 4](assets/005.jpg)

也可以用 Google 地图街景看一眼，明显是住宅楼的才选。

![图片 5](assets/006.jpg)

**第 3 步 — 选套餐**

点击地址后选 **Select Plan**，套餐最低 $4.99/月（地址不同价格有差异），平均约 $9.99/月，包含每月 30 封信件、5 页免费扫描、转寄手续费 $5（运费另算）。先选月付，用得顺再换年付。

![图片 6](assets/007.jpg)

付款后系统会分配一个邮箱编号（如 Unit #581），完整地址格式大致是 \`Ste 112 Unit #581, ...\`，填写银行申请表时银行可能会自动删掉 Unit 编号，没关系，收件人姓名对就行。

![图片 7](assets/008.jpg)

**第 4 步 — 完成 1583 公证**

1583 是美国邮政局的表格，授权 ATMB 代收你的邮件，**必须完成才能正式使用地址**。

流程：

- 登录后主页会提示 "Complete Verification"，点击进入
- 选择无 SSN，填写个人信息（护照签发省份填英文，如 BEIJING）
- Address ID 选 "Voter Card"，用身份证 + 翻译件代替（支付宝翻译约 60 元）
- 选择自助认证 "Use Own Notary"，费用约 $25
- 下载预生成的 1583 PDF，打开 [proof.com/customers/anytime-mailbox](https://www.proof.com/customers/anytime-mailbox) 进行视频公证
- 视频认证：用手机扫描二维码拍护照和身份证照片，然后加入视频会议（认证员全程英文，但很简单，只需确认姓名、选择签名样式，不超过 5 分钟）

![图片 8](assets/009.jpg)

认证完成后上传到 ATMB 等待审核，一般几天内通过。

![图片 9](assets/010.jpg)

**收到信件后**

ATMB 会发邮件通知，登录后台可以看到信封扫描图。选择 "Open & Scan"（扫描内容）或 "Forward"（转寄回国）。转寄费用：美国西部寄到中国，经济邮寄约 $20-30，带追踪的快递约 $50-80，两张银行卡重量约 0.4 磅。

### 第三步：拿一个美国实体电话号

Google Voice 虚拟号码**不行**。银行客服能识别 VoIP 号码，申请表上填 GV 号会被拒或触发人工审核。必须是真实的美国实体 SIM 卡。

**为什么在国内能用美国号码？— WiFi Calling**

WiFi Calling 是美国运营商提供的功能，允许通过 WiFi 网络拨打和接收美国电话，费率和美国本地通话相同，**不产生国际漫游费**。在国内只要连上 WiFi，就能正常接收银行短信验证码和客服电话。

iPhone 开启方法：设置 → 电话 → 打开"Wi-Fi通话"

> 注意：只有支持 WiFi Calling 的 SIM 卡才能开启此功能。

**⚠️**** 2025-2026 重要更新：WiFi Calling 在国内需要 DNS 配置**

T-Mobile 系列运营商（Tello、Ultra Mobile、US Mobile 等）的 WiFi Calling 服务器（IP 段 \`208.54.0.0/16\`）在中国大陆已被部分封锁。直接连 WiFi 可能无法激活 WiFi Calling。**必须**在路由器或代理软件中添加规则，将该 IP 段走代理。

Clash / Quantumult / Surge 用户：添加规则 \`IP-CIDR, 208.54.0.0/16, 代理节点\`

路由器用户：将 DNS 改为 \`199.85.126.10\` + \`199.85.127.10\`，或使用支持透明代理的固件（Merlin / OpenWRT）。

**推荐方案：Ultra Mobile PayGo（紫卡）**

$3/月，100 分钟 + 100 条短信 + 100MB 流量，T-Mobile 网络。相比 Tello，额外优势是支持中国移动/联通漫游信号（在没 WiFi 时仍可通过漫游接收短信），适合长期在国内使用。淘宝/闲鱼有售，也可官网购买。

> ⚠️ 保号注意：账户余额不足 $3 且超过 60 天未续费，号码会被回收。建议开启 Auto Pay。

**激活步骤（Ultra Mobile PayGo）：**

- 购买 SIM 卡（官网或淘宝）
- 连接美国 IP 后，打开 [my.ultramobile.com](https://my.ultramobile.com/) 激活
- 激活完成后，按上方 DNS/代理配置开启 WiFi Calling
- iPhone：设置 → 电话 → Wi-Fi通话 → 打开
- Android：设置 → 网络与互联网 → SIM 卡 → 选 Ultra Mobile → 打开 Wi-Fi 通话

**推荐方案：Tello — 适合需要灵活套餐的用户**

Tello 使用 T-Mobile 网络，支持 eSIM 即时激活，套餐可自由组合。官网 [tello.com](https://www.tello.com/)。

**第 1 步 — 注册账号**

打开 [tello.com/account/register](https://www.tello.com/account/register)，用邮箱或 Google/Apple 账号注册。

**第 2 步 — 确认手机兼容**

先用 [tello.com/bring\_your\_own\_phone](https://www.tello.com/bring_your_own_phone) 输入手机 IMEI 号，确认手机解锁且兼容 T-Mobile 网络。iPhone 基本都兼容。

**第 3 步 — 选套餐 + 购买 SIM**

打开 [tello.com/buy/custom\_plans](https://www.tello.com/buy/custom_plans)，自定义套餐：

- 通话：100 分钟（够用）
- 短信：无限
- 数据：0 或最低档（国内主要用 WiFi，不需要数据）
- 最低约 **$5-8/月**

SIM 卡类型选 **eSIM**（推荐，即时激活无需等待邮寄）或 Physical SIM（需要等国际快递，约 1-2 周）。

结账时填写美国地址（用 Anytime Mailbox 地址）和 Billing 信息（填中国地址也可）。支持信用卡、PayPal 付款。

**第 4 步 — 激活 SIM**

收到 SIM 后（或购买 eSIM 后），打开 [tello.com/activate](https://www.tello.com/activate) 完成激活。

> ⚠️ 激活页面需要美国 IP，国内用代理连接美国节点再操作。

激活步骤：

- 登录 Tello 账号
- 进入 Activate SIM 页面，输入 SIM 卡号或扫描 eSIM 二维码
- 选择之前购买的套餐
- 确认号码（系统会分配一个美国号码）
- 激活完成，手机重启

**第 5 步 — 开启 WiFi Calling**

iPhone：设置 → 电话 → Wi-Fi通话 → 打开

Android：设置 → 网络与互联网 → SIM 卡 → 选 Tello → 打开 Wi-Fi 通话

> ⚠️ WiFi Calling 无法连通时，参考上方 DNS/代理配置说明。

开启后，在国内连 WiFi 即可正常拨打、接听美国电话，费率与美国本地相同，**不产生国际漫游费**。

**保号注意事项：**

- 保持每月按时续费，账户余额不足会停号
- 建议开启自动续费（Auto Pay）
- 长期在国内也没问题，DNS/代理配置好后 WiFi Calling 可稳定使用

### 第四步：开美国 Checking 账户

押金卡需要一个美国银行账户来存押金和还款。

**最简单的方案：Wise**

Wise 可以完全在线开户，无需赴美，会给你一个真实的美国 Routing Number + Account Number。开户免费，充值用人民币转入即可。

**开户步骤：**

- 打开 [wise.com](https://wise.com/)，点击 **Register**，用邮箱注册
- 选择 **Personal account**（个人账户）
- 填写姓名、出生日期、居住地选 **China**
- 验证邮箱，完成基础注册
- 进入账户后，点击左侧 **Payments** → 选择 **USD（美元）**
- 首次使用 USD 账户需要提交地址证明（如 Anytime Mailbox 的账单扫描件）
- 审核通过后，进入 USD 账户页面 → 选 **Local** 标签

开通后你会看到完整的美国账户信息：ACH routing number + Account number + Account type (Checking)，还附带 Wise 的实体地址（存押金时 Capital One 会要求填写）。

![图片 14](assets/015.jpg)

存押金时用这里的 Routing Number 和 Account Number 填入 Capital One 即可。

注意：**Wise 还款容易触发 Capital One 风控**，拿到 Capital One 银行卡之后，建议同步申请 Capital One 自己的 Checking 账户来还款（在网银里直接申请，有了银行卡后不会被要求线下办理）。

### 第五步：申请 Capital One 押金银行卡

四件套到位之后，这步是最顺的一步。

**为什么选 Capital One？**

Capital One 是目前国内云居民申请美国银行卡成功率最高的银行，明确接受 ITIN，申请流程全在线，无需去线下分行。

**申请步骤：**

- 打开 [capitalone.com](https://www.capitalone.com/)，点击 Credit Cards → Credit Building
- 点击 **"See if I'm Pre-Approved"**，填入基本信息（姓名、地址、ITIN、出生日期）

![图片 15](assets/016.jpg)

- 如果预审通过，直接出银行卡；如果没通过，选押金卡申请

![图片 16](assets/017.jpg)

- 填写申请表时注意：

- US Citizen → **No**   - US Resident → **Nonresident（NRA）**   - 地址填 Anytime Mailbox 的私人地址

![图片 17](assets/018.jpg)

![图片 18](assets/019.jpg)

- 电话填你的美国实体号
   - 收入填 $50,000-$100,000（不要填太高，避免被要求提供税表）

![图片 19](assets/020.jpg)

- SSN 一栏填入你的 ITIN 号码

![图片 20](assets/021.jpg)

- 提交后等邮件，通常几小时到 1 个工作日

![图片 21](assets/022.jpg)

**两种押金卡：**

卡名                                       最低押金    返现         年费  
1. Quicksilver Secured    $200         1.5%          无
2. Platinum Secured        $49            无              无

推荐 Quicksilver，$200 押金，每笔消费 1.5% 返现，使用 3-6 个月后押金通常会被退还并升级为无押金卡。

**审核通过后：**

- 收到邮件要求补交材料 → 上传护照信息页 + ITIN 确认信扫描件
- 审核通过 → 收到邮件要求存押金

![图片 22](assets/023.jpg)

- 用 Wise Checking 账户存入押金（填 Routing Number + Account Number）

![图片 23](assets/024.jpg)

- 等 1-2 周，实体卡寄到美国地址
- 让地址服务商扫描转发 → 到手后激活，再设置网银

**激活注意事项：**

- **收到实体卡之前，不要在 App 上注册网银账号** → 容易触发风控
- 用卡背面的电话激活，准备好：完整卡号、ITIN、生日
- 激活后设置网银，尽量用**美国 IP**，不要 IP 跳来跳去

### 可能遇到的坑

**风控（Restricted）**

新卡使用后约 30-60 天内，Capital One 可能冻结账户，要求提供身份证明。

解封方法：

- 准备好：ITIN 确认信 + 护照 + Capital One Checking 账单（如果有）
- 传真给 Capital One（封信上有传真号），或者打电话反复沟通
- 说明自己没有 SSN，只有 ITIN，要求接受护照作为替代证件
- 通常 1-2 周解封

**Wise 还款风控**

不要用 Wise 直接还款 Capital One 银行卡。开卡后立刻在网银里申请 Capital One 自己的 Checking 账户，之后用那个账户还款。

### 之后的路线图

![图片 25](assets/026.jpg)

第一张押金卡的意义不是返现，是**建立信用记录**。把它当每月的固定开销，每月全额还款，信用分会稳步上涨。有了信用分，后面的路就平了。
