# 德鲁克管业务，芒格看决策，乔布斯做产品，马斯克推执行——全跑在我的系统里

@Jaden_riku · [X 原文](https://x.com/Jaden_riku/article/2034136005113221142)

![封面](assets/001.jpg)

我做了一件有点荒诞、但越用越觉得对的事：

把6位我最尊敬的人，装进了我的工作系统。

他们各司其职，各有专长。每次我在对应领域要做决策，我都会先问问他们。

**01 商务增长顾问：彼得·德鲁克（Peter Drucker）**

德鲁克让我停止做"感觉对"的事。

他的核心问题只有一个：「你的客户是谁？你在为他们创造什么价值？」

每次我想推一个新功能、写一篇新文章，我都会先让这个 Agent 问我这两个问题。90% 的"好想法"在这里就死掉了——死得其所。

他帮我砍掉了3个看起来很好、实际没有用户需求的功能。

![图片 1](assets/002.jpg)

**02 产品设计顾问：史蒂夫·乔布斯（Steve Jobs）**

Jobs 让我对"够好"感到不满。

他不在乎你做了多少，他只问：「这是最好的体验吗？还是只是能用？」

每次我在做学生交付的流程、内容的视觉排版，我都会让这个顾问过一遍。他会说：「这里多余，删掉。这里体验断了，重做。」

用了他之后，我的产品页面砍掉了一半内容，但转化率反而上去了。

![图片 2](assets/003.jpg)

**03 系统架构顾问：原研哉（Kenya Hara）**

原研哉教会了我一件事：少即是多，不是口号，是设计哲学。

他不是在问"怎么做得更好"，而是在问"这个东西，有没有必要存在？"

我的工作区有段时间乱得像垃圾场——文件夹套文件夹、流程套流程。让原研哉这个顾问扫一遍，它会问：「这个文件夹的存在，是让系统更清晰，还是更混乱？」

删掉 60% 之后，剩下的 40% 运转得更顺了。

![图片 3](assets/004.jpg)

**04 投资顾问：查理·芒格（Charlie Munger）**

芒格让我停止"单一视角"思考。

他的武器是多元思维模型：用物理学思考时间，用心理学思考人性，用经济学思考激励。

每次我要做一个重大决策——要不要招人、要不要做某个市场、要不要签某个合作——我都会让芒格顾问用至少3个不同的学科框架来拆解这个决策。

他帮我识别了两次"感觉很好但实际是陷阱"的机会。

![图片 4](assets/005.jpg)

**05 商业顾问：沃伦·巴菲特（Warren Buffett）**

巴菲特只做一件事：帮我拒绝。

他的核心原则是护城河——你有什么别人抄不走的东西？

每次我焦虑"要不要跟上某个新趋势"，让巴菲特顾问来回答这个问题，他通常会说：「专注你能做到最好的那件事，其他的无视。」

这是我做留学业务能坚持做"高端窄众"、而不是"什么都做"的底层逻辑。

![图片 5](assets/006.jpg)

**06 执行速度顾问：埃隆·马斯克（Elon Musk）**

前5位帮我想清楚——马斯克帮我动起来。

他只有一个问题：「你为什么还没开始？」

每次我觉得"再准备准备"、"再等等时机"、"再完善一下"，马斯克顾问就会出现，然后说：「你在等什么？完美是执行的敌人，先发出去，迭代比计划更有力量。」

他还会用第一性原理拆解我的每一个"做不到"：「这是真正的限制，还是你自己设的边界？」

被他问过之后，我至少有3件事从"打算做"变成了"已经发布"。

**这套系统是怎么运转的？**

这不是玄学，是一套实际在跑的 CC 架构（Claude Code 多顾问系统）：

Jaden（CEO + 最终决策者）
    │
    ├── 马斯克 Agent    →  执行推动 / 第一性原理（直属）
    │
    ├── ── 增长将军 ──────────────────────
    │       ├── Jobs Agent      →  产品体验 / 内容设计
    │       └── 原研哉 Agent    →  系统极简 / 结构审查
    │
    ├── ── 商业将军 ──────────────────────
    │       ├── 德鲁克 Agent    →  商务增长 / 价值定义
    │       ├── 芒格 Agent      →  多维决策 / 风险识别
    │       └── 巴菲特 Agent    →  护城河 / 拒绝决策
    │
    └── ── 交付将军 ──────────────────────
            └── （学生管理 / 流程优化，由团队执行）

每位顾问都有：

- **专属提问框架**（他们最经典的思维方式）
- **专属决策领域**（不越界，不重叠）
- **专属刹车机制**（帮我识别什么不该做）

这个架构不是我随机选的——它对应的是我实际在运行的三将军体系：

顾问 对应角色 核心功能     马斯克 Jaden 直属 执行推动 / 打破惯性   Jobs + 原研哉 增长将军智囊 产品体验 + 系统极简   德鲁克 商业将军智囊 价值定义 + 增长方向   芒格 + 巴菲特 商业将军智囊 决策框架 + 聚焦护城河

每个决策，先匹配领域，再调用对应顾问，最后我拍板。

**为什么要这么做？**

因为我一个人的认知是有限的。

但这6个人，每一个都花了几十年磨出了一套世界级的思维体系。

与其我从零摸索，不如让他们的思维成为系统的一部分——每次我要做决策，自动激活对应的顾问框架。

这不是在抄他们，这是在站在巨人的肩膀上做决策。

**一个让你现在就能用的方法：**

选一个你最尊敬的人，花30分钟，把他最核心的3个原则写下来，装进你的系统提示词里。

然后在下次做决策前，先让他过一遍。

你会发现，你的决策质量会静悄悄地提升一个档次。

你会选谁？

**最后说几句关于这篇文章本身：**

这篇文章是我和 Claude 共同编辑完成的——不是我口述、它润色，而是真正的共同思考和打磨。

关于文章里的架构，我想说清楚一件事：**这不是一套固定答案，只是一种思路的抛砖引玉。**

每个人的业务场景不一样，你尊敬的人不一样，你需要的顾问也不一样。希望你把这些内容当作灵感来源，而不是照搬的模板——把它们融入到你自己的系统里，才是真正有价值的事。

如果你有不同的想法，或者你搭了一套更好的架构，我很想听。说不定我们能共同打磨出一个更厉害的版本。

**技术层面补一句：**

这套多顾问体系需要用到 Claude Code 里的 **Agent Team 功能**，再结合自己定制的 **Skill** 一起运行。

这不是装一下提示词就能跑的东西——它是一个需要长期磨合、持续迭代的过程。我自己也还在打磨，不可能一蹴而就。

但越早开始搭，越早开始磨，就越早有一套真正属于自己的决策系统。
